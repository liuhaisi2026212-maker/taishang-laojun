# 开炉：开头与结构

先读[炉心](../taishang-laojun/references/core-mind.md)，尤其第一条破冰和第五条兑现。

## 先定一件事：观众看完应该明白什么

用一句话写下这条视频的内核：观众看完应该明白什么、相信什么、想做什么。这句话不一定出现在视频里（柳爷的一人公司那条，内核“挺赚钱但忙不过来”就是让观众自己看出来的），但每个镜头都要为它服务。选题还没定时，先回看火，不要随手套一个爆款开头。

**场景是工具**：已经有现场（海边、机场、工厂、商场）时，先问想用这个场景表达什么，再匹配经历和观点。背景本身不能证明成功、收入或身份。

## 开头：一句话完成破冰

开头的任务是让陌生人愿意多停一两秒（炉心第一条）。设计时按顺序想：

1. **这条靠哪种吸引力？**（娱乐 / 帮助 / 实力展示 / 下危机，见炉心附表。）吸引力决定了开头往哪个方向开：帮助类要让人觉得“有手就会”，下危机类要先把风险说出来，实力展示要第一眼就够厉害。
2. **观众心里此刻在防什么、在想什么？**把它替观众说出来，或者绕开它。柳爷叫这个“认心先发”：观众对你的防御（“又要卖课了吧”“肯定有坑”）在形成之前被说出来，比事后解释便宜得多。只用真实普遍存在的心理。
3. **一句话里能装进几个好懂的信息？**柳爷的“花了三个月，养了一群特别猥琐的 AI 打工仔”，一句里有付出、有好奇、有一厢情愿的想象。信息密度靠一句话里的多个点，不靠堆句子；每个点都必须一听就懂。
4. **第一句的主语是谁？**是观众能得到什么、正在遇到什么，还是创作者自己的经历？讲自己的开头（“我做了一年……”）对陌生人是废话，自己的经历往后放，当证据用（炉心第一条）。
5. **有没有顺着贪和懒？**帮助类内容的开头，给观众一条省力、舒服、能变厉害的路，比讲道理有效。但承诺要比证据小一点，下一秒就能用画面兑现；说成“用了就爆款”，观众早有抵抗力。
6. **开头的语气也在说话**：“刚下飞机就遇到一件特别恶心的事”的着急感，告诉观众这是随手拍的、真的。
7. **手里有没有东西**：能拿到镜头前的实物、成品、屏幕，第一眼就让人想问“他手里那是什么”。比空口说有说服力，开头的画面也更丰富。
8. **能不能借一句天生让人想听的说法**：“最划算的一笔投资”“今年最值的一次”这类话，天生让人想听下去。能借，但这句话放在用户身上必须是真的；带点调侃、笑着说可以，观众追问一句“真的吗”，得接得住。编出来的收益、身份，不借。

**几样东西朝同一个方向**：第一句、表情、字幕、手里的东西、标题，各管一部分，但要指向同一件事，合起来让观众脑子里出现一个完整的画面。交之前把这几样摆在一起看一遍。

几种常见的开法（候选，不是模板，选哪种取决于上面这些问题的答案）：
- **反着说**：大家都在说好，你说缺点（“一人公司有个致命的缺点”）。只在确实有被忽视的代价时用，作用是建立“你懂、你不骗我”。
- **反差定性**：用一句话说清“这是什么”，同时带一个和身份不符的反差（技术博主说“这是一期普法视频”）。
- **付出 + 好奇 + 想象**：AI 打工仔式。
- **现场突发**：机场式。必须有现场的东西能马上接住。
- **想象空间**：海边式。只摆出自己的经历，让观众自己替你说出结论。
- **实物 + 留白**：手里拿着一样东西，说出它能做到的一件反常的事，不讲完它还能干什么（见下面“留白”）。

**柳爷最常改掉的开头**：利益画饼（“学会了能省几万、躺赚”）和自嗨式设问（“为什么我今天非要跟你们讲这个”）。观众不关心你为什么要讲，只关心发生了什么。

## 紧接着：勾证衔接，最好接成钩子链

开头抛出的期待，**下一句、下一个画面**就要兑现：真实的事件、动作、演示、截图、数据。兑现不了，观众会觉得你夸张，直接划走。柳爷的机场视频，“恶心的事”后面马上是广告牌；广告牌又引出“这什么意思”，再接正文。这就是钩子链：每一个证据同时是下一个钩子。

节奏上要快：观众上一秒的想象还没落地，下一秒证据就到了。

**演示用的例子要选观众自己的处境**：录屏演示、举例子时，选这条的目标观众身上最常见的那个情况，让人一看就觉得“说的就是我，我也试试”。选一个只有少数人才有的处境（比如给泛自媒体观众演示“县城理发店”），大部分人会觉得跟自己无关。最好的例子来自观众自己：评论区、私信里真有人问过的那句话。

证据不只有结果。展示你查了哪些别人想不到的维度、怎么拆问题（世界杯预测的思路），思考过程本身就是能力证明。没有经历不编，可以做能检查的演示并如实标明。

## 中段：用事件推进，做减法

- **用案例衬托内核**：直白说没人信。用一件具体的事让观众自己得出结论（炉心第三条）。
- **减法**：别人讲十个插件，柳爷只讲两个并说清为什么。一两件关键事说透，胜过罗列所有工具。删掉不服务内核的信息。
- **外部验证用在观众“还有点怀疑”的地方**：海边视频里的大厂 token KPI。它的作用是消除怀疑，不是替你背书；拿不出可查的外部依据就不加。
- **标题、口播、画面分工**：开头要下钩子、要反常、要带情绪，两秒装不下视频的总结时，把“总”交给标题；画面负责展示，三处不要重复堆同一句话，但要讲的是同一件事。
- 有演示时保留关键操作和前后对照，不只写开头结尾。

## 留白：说了，又像没说

有些内容最有力的地方，是让观众自己把话补完。观众觉得自己听懂了你的意思，会在评论区接着往下说；你也不用说一句绝对的话。三种常用的做法：

- **潜台词立人设**：不说“我很厉害”，说一句能让人推出来的话。比如“折腾了一圈，终于开始玩硬件了”，观众自己会想到“软件他已经玩明白了”。
- **对比抬高**：不说“技术含量高、用处大”，拿观众公认最难的那个来比：“最封闭的那个都拦不住它，别的就更不用说了。”
- **只给事实和可能性，不下结论**：摆出它能做到的一件事，停在这里，把“还能拿它干什么”交给观众。结尾可以直接问一句，但只问一句。

边界：

- 每一句单拿出来都是真的，能演示、能查；
- 不暗示收益，不暗示“用它能赚多少钱”。留白是让人去想“还能怎么用”，不是去想“能赚多少”；
- 留白之前想一想：这个空最可能被什么人、往哪个方向补？比如说“它能完全控制手机”，就会有人往“挂机刷游戏、自动搬砖”上补。招来的这拨人如果不是用户想要的，就换一个留白的方向，或者在画面里把方向定住。

帮助类、教程类内容不靠留白，靠讲清楚；留白适合实力展示、新奇的东西和让人向往的状态。

## 收尾：给理由，然后干脆结束

- 观众需要两个理由：**看完的理由**和**关注的理由**。柳爷的 AI 打工仔：“这些东西我都会给到大家”（关注的理由），“但前提你得先学会怎么用”（看完的理由）。
- 用户的目标是招学员、接单、咨询时，结尾必须让想要的那群人知道“去哪找你”（按平台允许的方式，比如主页、置顶），否则内容做对了，转化也断了。
- 金句落地后短短一句就结束，不拖一段互动话术。观众一听到“大家平时怎么样、欢迎评论、下期我带你们”，就知道正片结束了，马上划走。
- 想涨粉时，结尾亮出一个**真实存在、真能拿到**的东西（模板、清单、工具），比单纯求关注有效（见[改稿六刀](../taishang-laojun/references/edit-six-cuts.md)“资产饵”）。没有就不硬凑。

## 结构：按素材选，不统一套

- **教学/分享资源**：柳爷的五段式，钩子 → 证据 → 承诺 → 条件 → 指令（出处是 AI 打工仔那条）。承诺必须能兑现；条件要说真实门槛会在哪一步出现、卡住了去哪里问，这个提问入口本身就是承接口；指令服务这次的目的，不是每条都要评论扣 1 或进群。
- **记录/故事**：事件 → 行动 → 变化。
- **专业答疑**：问题 → 解释/演示 → 结论。
- **热点判断**：跟观众有关的那个结论先说（他该怎么办、会受什么影响）→ 这件事是什么，当证据 → 为什么会这样 → 以后会怎样。最有用的那句放在最后，等不到的人早就划走了；结论换谁说都成立（“赶紧用起来”“要跟上时代”），就说明还没想到这件事对这群观众到底意味着什么。
  新闻里的具体数字、日期、法条、原话，交稿时标出处、提醒用户发之前核实。选举、党派、国家之间的冲突这类话题，评论区容易吵起来，招来的人也会跑偏，选题时就提醒用户。

依据素材选结构，并用一句话说明为什么选它。

**时长服从信息**：柳爷的 Codex 两件事只有十来秒。柳爷的理解是平台整体偏好能留住人的长视频，但十几秒能说清的不拉长；有必要的过程也不硬缩。

## 已经拍完，要定剪辑

只按实际能读到的素材（片段说明、逐字稿、截图）给取舍和顺序。没读过的视频不能说看过，不编时间戳，不声称完成了剪辑。素材不够就请用户描述有哪些片段。

## 交付

按请求给：
- 1–2 个第一句话（用户自己的说法），以及它为什么适合这次的观众和素材；
- 紧接着的证据或画面；
- 必要的中段推进和收尾；
- 可执行的镜头建议；
- 什么条件变了就要换开头。

只要改开头就只交开头。**完整逐字稿由回炉负责**：用户要整稿时，把结构交给总入口衔接回炉，不让用户来回跑。

写句子时用用户自己的说话方式（见[去AI味](../taishang-laojun/references/deai-rulebook.md)）。AI 写出的初稿，按[改稿六刀](../taishang-laojun/references/edit-six-cuts.md)审一遍再交。六刀里的秒数、字数是柳爷在抖音上的经验值，按平台和素材调整。
