# 发前合规排雷：少踩平台大雷

稿子写顺了，发出前顺手过一遍这关，减少无谓的下架、限流和扣分。

先说清楚边界：
- 本卡只帮创作者把话说准确、把常见大雷避开，**不提供绕平台规则、打擦边球或暗示违禁功效的改法**。
- 平台细则随时会变，各细分行业还有各自的准入要求；本卡**不保证 100% 过审**，也不能替代平台官方规则和专业审核意见。

## 什么时候过这一关

纯生活记录、日常聊天不用每次都查，免得把话写僵。遇到下面任意一种情况，交稿前或发布前过一遍：
- 内容涉及带货、团购、引流、收费服务或商业合作；
- 涉及高敏感领域：健康医疗、普通食品与膳食营养、美妆护肤、金融理财、法律、教培考证、热点新闻；
- 用户明确问“这条能不能发”“会不会违规”“怎么排雷”。

## 全赛道六大高频雷区（口播、字幕、封面、画面一起查）

1. **极限词与绝对化承诺**
   - 常见雷区：最（最好、最大、最强、最有效、全网最低）、第一、顶级、首选、绝对、100%、彻底、永久、万能、一定有效、包过。
   - 怎么改：把绝对说法收回你有真实证据的范围，讲清楚适用条件或个人真实体验，不替所有人打包票。

2. **高危行业越界与超范围功效**
   - 普通食品、膳食营养品、普通化妆品不能讲医疗作用或超出类目的功效（如减肥、减脂、美白、祛斑、治病、预防、抗炎、助眠、调理代谢）。
   - 健康、医疗、金融理财、法律、考证类内容，不能删掉必要限定和风险提示；不能承诺“稳赚不赔”“零风险”“躺赚”，也不能下绝对化专业结论。

3. **虚构人设、官媒背书与无凭证促销**
   - 没有对应资质证明，不要自称医生、营养师、资深律师、品牌研发人员或权威专家，也不要穿白大褂、戴听诊器等医护装备制造专业错觉。
   - 不要借央视、电视台、国家级、权威机构认证给自己背书。
   - 没有真实依据或未按平台要求展示凭证时，不要喊“原价多少、过两天恢复原价”“全网最低价”“X 大专利”。

4. **公域站外导流（最容易被连坐压流量）**
   - 公域口播、字幕、封面、置顶评论、主页简介、背景图以及平台内粉丝群里，不要硬写微信、加微、加V、微信号、二维码、扫码、手机号、外部网址及谐音代称。
   - 承接只走所在平台当前允许的路径（平台内私信、官方组件、官方店铺、平台合规群工具等），拿不准先查平台官方规则。

5. **画面、字幕、隐私与 AI 标识盲区**
   - **字幕和封面同样会被机审**：字幕不要比口播多写敏感词或夸大词。
   - **画面雷区**：避免缺乏依据的前后对比图；拍摄和剪辑时扫一遍背景，避开国旗、敏感机构招牌、未授权商标或杂乱二维码。
   - **隐私与肖像**：非公众人物不要直接露出真名、正面清晰照或聊天隐私，必要时打码脱敏。
   - **AI 生成内容**：用了 AI 生成的画面、声音或数字人，按平台要求勾选自带的“AI 生成”声明。

6. **搬运、未核实数据与争议引战**
   - 搬运他人视频或裁剪影视综艺片段却无实质二次创作，极易被判低质搬运或侵权。
   - 新闻事件、法案条款、金额与比例要核实并标明出处，查不到的数字不上口播也不上字幕。
   - 避免借敏感社会事件蹭流，或刻意制造性别、地域、群体对立。

## 怎么查、怎么交

1. **先跑机械初筛（能运行代码时）**：在总入口目录下运行 `python3 scripts/compliance_linter.py 稿子.txt`（也支持 `--text "文案"`），快速扫一遍高频红线词和提醒词。脚本只做机械预检：命中后要结合语境判断是否真违规，0 命中也不代表绝对安全。
2. **再做人工复核**：逐项扫一遍上面的六大雷区，重点补查脚本看不到的东西——画面、封面、字幕、人设装扮、主页简介和前后语境。
3. **只列真有问题的地方**：按“原句或画面 → 踩哪类雷 → 合规改法（保留原有信息，收回夸大与越界）”给出能直接替换的版本；如果整条方向本身撞死线（比如普通食品硬讲疗效、教人绕审核、虚构专家背书），直接提醒换角度重写。

## 靠谱的官方规则去哪查

网上的“万能违禁词大全”大多东拼西凑、容易过时。拿不准某个细分品类或新规时，直接查一手官方来源：

- **国家通用底线**：《广告法》、市场监管总局《互联网广告管理办法》、七部门《网络直播营销管理办法》。
- **抖音**：[抖音安全与信任中心](https://95152.douyin.com)（公开的社区规范、审核说明与专项治理），或抖音 App 内「我 → 右上角菜单 → 设置 → 抖音安全中心 / 抖音规则中心」；涉及带货与商业投放，查巨量引擎 / 巨量学的行业审核规则。
- **微信视频号**：微信内「创作者中心 → 创作者服务 → 带货中心 → 规则中心 / 小喇叭公告」（运营规范与微信小店带货规则）。
- **小红书**：App 内「创作服务中心 → 规则中心 / 社区公约」及蒲公英商业合作规范。

如果视频已经发出去，却遇到发不出去、卡审或疑似限流，转到[反馈复盘](feedback-review.md)走四步排查。
