太上老君 · AI炼丹炉

把别人的爆款，炼成你自己的视频　·　版本 0.7.2

总控台：按你此刻在哪，调对的兵器有灵感就用自己的事直接拍；没灵感就刷对标、拆爆款、存弹药库。需要认识你时才访谈。AI 下判断，你来校准。

炉心：七条底层判断

  • 破冰先于一切陌生人只给你一两秒，先让他感兴趣，信任靠后面的证据挣
  • 观众在想什么想躺平的贪和懒、没意识到的痛点、对你的防御
  • 用事件衬托内核直白说没人信，让观众从一件事里自己看出来
  • 判断力胜过教程热点是载体，判断是内容；只露果，不穷尽
  • 钩子马上兑现下一秒就用画面或事件接住，接住它的又是下一个钩子
  • 展示什么，吸引什么人成品招要成品的，过程招学习者，忙碌招求职者
  • 适合自己的才是兵器对标、工具、表达都放进自己的条件里掂量

七个模块（按需调用，不必从头走完）

01 选材 · 找对标拆爆款

  • 找条件一致、想吸引的人也一致的对标
  • 拆开看它为什么爆：撑着它的是哪一两个机制
  • 复读、客户、替换三关掂量，用你自己的事接住

交付：保留什么、换掉什么、用你的哪件事接住

柳爷的案例：柳爷找对标只看条件一致的口播号；主动搜的常不对，无意刷到、想一直看的才是。
学的是推理过程，换成你自己的场景和材料重新推一遍。

02 看火 · 选题决策链

  • 起点 → 观众最关心什么 → 你拿什么接住
  • 靠哪种吸引力：娱乐 / 帮助 / 实力 / 下危机
  • 会招来谁？开头的承诺拿什么兑现？

交付：1–3 个私人定制方向，推荐一个

柳爷的案例：世界杯：抢热点 → 球迷最关心比分 → 用 AI 做预测工作台 → 摊开思考维度。
学的是推理过程，换成你自己的场景和材料重新推一遍。

03 丹方 · 系列策划

  • 判断型、现场型、事件型、串联型、上手型，选一个当主线
  • 服务观众不服务自己；列不出五期就撑不住
  • 一个人拍得动吗？一期期拍下去，来的是谁？

交付：固定什么、换什么、首批五期、第一期怎么拍

柳爷的案例：像素范每周只讲一件事和自己的判断，讲多了就成了“AI 的内容看他就够了”。
学的是推理过程，换成你自己的场景和材料重新推一遍。

04 开炉 · 开头与结构

  • 一句话里装几个好懂的信息，完成破冰
  • 勾证衔接，最好接成钩子链
  • 收尾给看完的理由和关注的理由，然后干脆结束

交付：第一句、证据画面、推进、收尾和理由

柳爷的案例：机场：“刚下飞机遇到件恶心事” → 马上接一块广告牌 → 广告牌又是下一个钩子。
学的是推理过程，换成你自己的场景和材料重新推一遍。

05 回炉 · 完整成稿

  • 逐字稿是弹药库，先存不急着改
  • 先有场景和目的，再翻弹药库找观点
  • 借观点不借脉络；AI 初稿按改稿六刀做减法

交付：可以直接念的完整稿

柳爷的案例：柳爷改 AI 初稿时，信息大多保留，动作几乎全是“删”。
学的是推理过程，换成你自己的场景和材料重新推一遍。

06 收丹 · 标题

  • 标题不等于选题，剪完再想
  • 补信息 / 给期待 / 替开头当“总”
  • 跟我有关：认人、认事、认心，用陌生人的眼睛检查

交付：需要几个给几个，每个说清“有关”在哪

柳爷的案例：“一人公司有个致命的缺点”：把观众心里那句“肯定有坑”变成标题。
学的是推理过程，换成你自己的场景和材料重新推一遍。

07 成丹 · 变现承接

  • 点赞、咨询、成交分开看
  • 预期用户 ≠ 实际用户：纠偏、顺势，或拒绝
  • 一个能兑现的交付，只走平台允许的承接

交付：一个交付、承接路径、交付成本与观察点

柳爷的案例：一人公司招来求职者：可以纠偏，也可以顺势为他们设计一个交付。
学的是推理过程，换成你自己的场景和材料重新推一遍。

贯穿全程

  • 底味访谈需要认识你时才用：让你越聊越想说，AI 替你总结成使用者档案
  • 反馈复盘沿链条找第一个偏掉的环节，再选纠偏或顺势
  • 底线不编经历和数字 · 钩子要兑现 · 合规承接 · 不服务害人的需求
